# Game-daqian V2

这一目录是新的协议化自动化实验线，旧版 `cron_farm.py` 不动。

## 当前阶段

先用现有浏览器登录态进入游戏，同时记录 WebSocket 收发帧，并给丹界药田的关键动作打 marker：

- 进入游戏
- 洞府
- 丹界药田
- 点开地块
- 收获
- 搜索青石斛
- 播种青石斛

运行结束后会输出每个 marker 附近出现的消息 ID，并上传完整 `frames.jsonl`。下一步根据这些真实协议帧做直接 WebSocket 客户端，把截图识别和坐标点击逐步移除。

## 原则

- 不覆盖旧版。
- 不把登录 token 打到 Actions 日志。
- 抓包 artifact 只短期保留。
- 新功能按 task 模块扩展，不继续把所有逻辑堆进一个脚本。
